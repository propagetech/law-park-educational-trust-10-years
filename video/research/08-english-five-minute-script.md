# 08 · English Five-Minute Script

Two complete versions of the anniversary welcome film.
**Version A** is the formal event script, written to open a hall.
**Version B** is the warm cinematic documentary script, written for the website, YouTube and donor communication.

Both run to the same visual master and the same eight-beat arc. Both use only claims marked VERIFIED in [02-evidence-table.csv](02-evidence-table.csv), plus year-specific numbers that nothing in the repository contradicts.

**Neither script states a cumulative student, village or district total.** Those figures conflict four ways across the repository. See `06`, question 1.

Claim IDs appear in square brackets beside every fact-based line. Lines needing approval are marked **[TRUSTEE CONFIRMATION REQUIRED]**.

**Reading convention**
- `VO:` spoken narration
- `OST:` onscreen text, not spoken
- `[pause 2s]` deliberate silence for the image to carry

## Production notes for both versions

**Numbers spoken aloud.** Numerals are written out in the VO ("a hundred and fifty", "seventy-five per cent") because narrators read digits inconsistently. Onscreen text uses figures.

**Names.** Only three individuals are named in either script: Charulatha M. R., S. M. Manjunatha, and the awarding body. No child is named. No donor is named individually, because naming some and not others in a five-minute film creates a problem the credit roll solves better. See `13`.

**What was deliberately left out, and why**

| Omitted | Reason |
|---|---|
| Any cumulative student, village or district total | Conflicts four ways. `06` Q1. |
| "Across India" | Every named location is in Karnataka. `06` Q1. |
| The presenting ministers at the award | Not on the certificate, no photographic evidence. `06` Q3. |
| Section 80G | Single unverified source, and it is a tax claim. `06` Q7. |
| Meena, Raju, Sunita | Composite characters with invented names. `02` EXC-01. |
| Any individual child's circumstances | Safeguarding. `02` EXC-02. |
| Marital relationship of the trustees | Single source, personal. `06` Q12. |
| The three placeholder partner NGOs | Unverified template content. `06` A4. |
| All 20 supporter "quotes" from the website | No source document. `06` A5. |
| "Children of acid-attack victims" | Appears only in outbound letters, with no supporting programme record. `02` MIS-06. |

**If the trustees answer Q1 with a confirmed figure**, one line can be added at the end of section C in either version: *"In ten years, that has come to [N] children."* Place it after the 2025 line, before the section break, and add a matching statistics card. Nothing else in the script needs to change.
